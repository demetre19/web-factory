# intent-attribute: value

Measured from page copy with a closed cue lexicon (`intent.py` ATTRIBUTES); every site carries the matched cue as evidence, so an attribute is a quotation, not an impression.

## Use

When a brief claims this attribute, these are the choices the corpus pairs with it; a variant that claims it and picks the opposite must declare the deviation.
