# pattern-marketplace-home-hero-stacked-hero

Stack the promise as centred text with no media column — reserve this for pages without a strong hero image. On marketplace hero sections built for buyers comparing listings, hold imagery at `text-led`, CTA restraint `single-primary`. This signature appears in 63% of 30 annotated screens (layout-archetype, image-led-ratio, cta-restraint), so it is the default, not a variation: select it unless the brief gives a named reason to deviate, and log that reason (P.8).
