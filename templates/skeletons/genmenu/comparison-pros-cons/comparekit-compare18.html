Dark 3-Column Pros & Cons Matrix

Frontend Rendering Strategy Comparison

Static Generation (SSG)

Best for: Marketing sites & docs

Pros
  • Instant CDN edge cache hits
  • Zero origin compute cost per view
Cons
  • Full rebuilds slow down at 10k+ pages
  • Stale data without ISR webhooks
Recommended Default

Streaming SSR

Best for: Dynamic SaaS & commerce

Pros
  • Always fresh, personalized HTML on first byte
  • Progressive Suspense boundaries keep TTFB fast
  • Full SEO metadata without client waterfall
Cons
  • Requires active server or edge worker runtime

Client-Only SPA

Best for: Authenticated internal tools

Pros
  • Simple static bucket hosting
  • Instant client-side route transitions
Cons
  • Blank shell or spinner before JS hydrates
  • Poor organic crawler indexing
