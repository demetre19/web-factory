1. Spatial Orientation

Wayfinding communicates where a person is within an information hierarchy, how they arrived, and what adjacent routes remain available without forcing memory recall.

2. Semantic Landmarks

Wrap ordered breadcrumbs and table-of-contents lists in <nav> elements with descriptive aria-label attributes and mark the current destination with aria-current.

3. Density Calibration

High-frequency utility workflows benefit from compact single-row controls, whereas multi-stage onboarding flows need generous spacing for descriptive helper copy.

4. Keyboard Focus Order

Every interactive segment and step button uses native <button> or <a> controls with visible focus rings so keyboard users move predictably along the trail.
