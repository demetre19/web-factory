## What verified clean

- **Split mechanics**: domain-grouped 75/25, 8 seeds, bank rebuilt from train only (`score.py:762-803,891-905`), cross-fit OOF (`:831-850`), `validate` refits (never reads `fitted-weights.json`), committed index backend `nomic:nomic-embed-text`.
- **Quarantine enforcement on positives**: 0/2700 `genotypes.jsonl` records match quarantined slugs; `genome.load`, `build_patterns.load`, `score.build_dataset` all call `filter_records`. Schema drift: 0/174 web + 0/44 negatives metas miss required keys.
- **No silent text-embedder fallback at query/index-pinned time**: explicit `--backend` + daemon down → `SystemExit` (`patterns.py:284-287,219-226,455-460`); `--vision`/missing-means failures also loud.
- **Artefact risk (resolution)**: CLIP preprocess resize+center-crop 224² destroys absolute resolution; `img_fit` is pure cosine, no size features. Residual: aspect-ratio channel (Mobbin tight crops vs fixed-window negative bands) survives only as center-crop content — weak, unmeasured.
- **Threshold honesty**: anti gates (0.33/1.8), `min_n=10`/0.60, ladder 1.00-0.75, `macro_micro` 0.8/0.35, PS thresholds are a priori constants — the leak is *where* cuts were swept (full corpus), not hidden tuning of the gate values.
- **Anti support healthy**: 194-290 negatives per rule (neg rates 0.749/0.829/0.800, lifts 9.23/7.23/3.75 in JSON; doc lifts 9.74/7.45/3.90 stale — F9).
- **Tile sampling**: quarantined `zaha` tile = genuine Cloudflare challenge (correct catch, wrong reason string); `aman`/`serhant`/`compass` tiles = live pages (wrong catch — F1).
